المسار البصري الاختياري — Claude API (يُرسل صفحات خارج الجهاز)

لا يُرسل أي شيء إلا بعد موافقتك الصريحة لكل ملف. تُرسل الصفحة المختارة فقط مباشرة من متصفحك إلى api.anthropic.com بمفتاحك، وتُحتسب التكلفة على حسابك. وفق سياسة الاحتفاظ بالبيانات لا يُحتفظ بمحتوى الطلبات افتراضيًا ولا يُستخدم للتدريب دون إذن — تحقق منها مقابل اتفاق السرية مع عميلك.
