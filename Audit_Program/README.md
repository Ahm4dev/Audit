# MEAP — البرنامج الرئيسي للمراجعة الخارجية (v4.3.7) — نسخة مقسّمة

هذا المشروع هو نفس الملف الأصلي `Master_External_Audit_Program_v4-3-7.html` بعد تقسيمه إلى ملفات صغيرة مرتبة في مجلدات،
**بدون أي تغيير في الكود الفعلي** (التقسيم قصّ فقط؛ الأسطر نفسها). افتح `index.html` مباشرة في المتصفح (لا يحتاج خادمًا).

## الهيكل

```
MEAP/
├─ index.html                  ← نقطة الدخول: يحمّل كل ملفات CSS و JS بالترتيب الصحيح
├─ css/                        ← التنسيقات (الترتيب مهم: الأحدث يغلب الأقدم)
│  ├─ base/                    ← الخطوط، المتغيرات (tokens)، الـ reset
│  ├─ layout/                  ← الهيدر القديم، تبويبات الارتباط، تخطيط الصفحة
│  ├─ components/              ← بطاقات، جداول، نماذج، تسجيل الدخول، التنبيهات
│  ├─ print/                   ← طباعة A4
│  ├─ themes/                  ← الثيم الداكن/الفاتح والكثافة
│  ├─ modules/                 ← تنسيقات خاصة بوحدات (الإجراءات، ميزان المراجعة)
│  ├─ v4/  v5/  v6/            ← طبقات التحديثات المتتالية (القائمة الجانبية، الهيدر الجديد…)
├─ js/
│  ├─ init/theme-init.js       ← يطبّق الثيم واللغة قبل أول رسم (يجب أن يبقى أول سكربت)
│  ├─ data/                    ← البيانات الثابتة فقط (ثوابت): الأصول، الدورات، أوراق العمل، القوالب، PBC…
│  ├─ core/                    ← الأدوات المساعدة، التخزين، المستخدمون والمصادقة، محرك البيانات
│  ├─ ui/                      ← مكونات الواجهة: التنبيهات، النوافذ، الجداول
│  ├─ views/                   ← صفحات العرض: لوحة المتابعة، البرنامج، القوائم المالية، المخاطر…
│  ├─ modules/                 ← الوحدات الكبيرة: أوراق العمل، ميزان المراجعة، الموافقات، النسخ الاحتياطي،
│  │                             التصدير (Excel/Word/PDF)، اختبار القيود، البحث، الاختبار الذاتي
│  ├─ app/                     ← البوابة والتوجيه والإعدادات، الأحداث ودورة الحياة، و 44-main.js (يستدعي boot)
│  ├─ v4/                      ← طبقة V4 (ميزان المراجعة، الحسابات، الكتالوج، العينات، التحليلات، الغلاف…)
│  └─ standalone/              ← سكربتان مستقلان: إبلاغ ارتفاع الـ iframe، إخفاء الهيدر عند التمرير
├─ assets/fonts/               ← خطوط MEAP Plex (woff2) — كانت مضمّنة base64 داخل الـ CSS
├─ tools/build.js              ← يدمج كل شيء في ملف HTML واحد مستقل
└─ dist/MEAP-standalone.html   ← ناتج البناء الجاهز (ملف واحد، يعمل بدون أي ملفات جانبية)
```

## قواعد مهمة للصيانة

1. **ملفات JS هي سكربتات عادية تشترك في نطاق عام واحد** (بدل الـ IIFE الواحدة الضخمة في الأصل)،
   لذلك أي دالة أو ثابت معرّف في ملف يمكن استخدامه في الملفات التي تُحمَّل بعده، وكذلك داخل الدوال في أي ملف.
2. **الترتيب في `index.html` هو المرجع الوحيد**: `data → core → ui → views → modules → app → v4 → main`.
   الكود الذي يُنفَّذ فورًا عند التحميل (خارج الدوال) لا يجوز أن يستدعي شيئًا معرّفًا في ملف لاحق.
   تشغيل التطبيق نفسه يتم في آخر ملف (`js/app/44-main.js`) بعد تحميل كل شيء.
3. **لإضافة ملف جديد**: أنشئه في المجلد المناسب، ثم أضف وسم `<script src>` أو `<link>` في `index.html` في الموضع الصحيح.
   ابدأ ملفات JS بـ `'use strict';`.
4. **تجنّب تكرار أسماء الدوال بين الملفات**: في الأصل 12 دالة معرّفة مرتين (آخر تعريف هو الفعّال)، وقد بقيت كما هي
   حفاظًا على السلوك: `wpDef, syncCustomWPs, navHTML, tabsHTML, navFit, rowHTML, buildAccounts, tbMapOf,
   suggestLine, renderEng, wpSt4, catProg` — النسخة الأولى في `js/modules|views|app` والنسخة الفعّالة في `js/v4/`.
   يُستحسن مستقبلًا حذف النسخ القديمة بعد التأكد.
5. ملف `js/modules/19-tb-worker.js` يُحوَّل نصيًا (`toString`) إلى Web Worker، فلا تستخدم فيه أي متغيرات من خارج الدالة.

## البناء كملف واحد

```bash
node tools/build.js                  # ← dist/MEAP-standalone.html
node tools/build.js out/MEAP.html    # ← مسار مخصص
```

لا يحتاج أي حزم. الأداة تقرأ الترتيب من `index.html` وتدمج CSS و JS والخطوط (base64) في ملف واحد.
استخدم هذا الملف عند التضمين داخل iframe أو رفعه كصفحة مفردة أو في بيئة تمنع تحميل ملفات خارجية.

## التحقق الذي أُجري

تمت مقارنة الملف الأصلي مع النسخة المقسّمة ومع ملف `dist` في Chromium: نفس شاشة الإعداد الأولى،
وإنشاء حساب وشركة وارتباط، ثم فتح 140 مسارًا/صفحة — النتائج متطابقة نصيًا، ولا توجد أي أخطاء في وحدة التحكم.

## تعديلات v7 (تبسيط وإصلاح)

- **إصلاح الأهمية النسبية (A500):** (1) الدالة `num()` صارت تقرأ الأرقام العربية ٠-٩ (كانت تُقرأ صفرًا فلا تُحتسب الأهمية)،
  (2) زر «اختيار» المعيار لا يكتب صفرًا عندما لا تكون حسابات الميزان مربوطة ببنود القوائم، بل يعرض تنبيهًا ورابطًا للتبويب،
  (3) تصميم الورقة أبسط: ملخص OM/PM/CT ثم ثلاث خطوات، والتفاصيل الثانوية في أقسام قابلة للطي.
- **حذف أوراق غير مهمة (390 ← 298 ورقة):** أوراق الطلبات/الاستفسارات المكررة مع PBC، نسخ «النموذج» المكررة للخطابات،
  ورقة «التقديرات» للمجالات التي لا تقديرات فيها، وأوراق الاستفسار لكل مجال، ومكتبات قديمة مكررة (B-01..04، D-01..16، Y-01..20، …).
  القوائم في `js/data/11-catalog.js` (`CAT_DROP`, `CAT_NOEST`, `CAT_RETIRE`) وللتراجع عن أي حذف يكفي إزالة المرجع منها.
  الاستفسارات تُسجَّل الآن من تبويب «الاستفسارات».
- **تصميم أقل ازدحامًا:** ترويسة الورقة مختصرة، الاعتماد/الجاهزية/التعليقات/التوقيعات/المرفقات/الروابط في أقسام قابلة للطي،
  وأقسام ورقة المجال صارت تبويبات بدل صفحة طويلة. الملفات: `css/v7/26-simplify.css`, `js/v4/44-simplify.js`.
  الطباعة تعرض كل شيء تلقائيًا.
